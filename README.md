# Burrow 地洞

Burrow 是一款运行在 Android 设备上的 AI 对话与 Agent 应用。

它既可以作为日常 AI 聊天客户端，也可以在需要时进入终端模式，让 AI 在手机上处理文件、编写代码、运行命令和完成更复杂的任务。

> **Burrow** 意为“地洞”。它代表一个独立、私密且可控的工作空间，也象征着 AI 深入任务、理解问题并完成工作的过程。

## 主要特性

- **AI 对话**：支持连续对话、流式输出和 Markdown 渲染。
- **Agent 模式**：让 AI 使用终端、文件和任务工具完成实际工作。
- **内置终端**：可以在应用内查看和使用 Linux 终端。
- **Linux 基座**：可选择适合自己的发行版环境，并选择中国大陆或国际下载源。
- **沙箱保护**：将 Agent 的工作范围限制在任务环境内。
- **检查点与回退**：可以查看任务变更，并在需要时回到之前的状态。
- **多会话管理**：不同对话拥有独立的历史和工作空间。
- **系统提示词**：可设全局提示词，也可给单个会话单独设一份覆盖它；
  对不支持 system 消息的服务提供兼容写法。
- **发送图片**：可从相册选图或直接拍照；对话模型看不了图时，
  可以先让视觉模型把图描述成文字再交给它。
- **消息操作**：支持复制、重新生成、编辑重发、回到指定消息和删除后续对话。
- **Skills**：可为 Agent 扩展不同领域的任务能力。
- **记忆与长对话**：适合处理持续时间较长、信息量较大的任务。
- **浅色与深色外观**：界面可跟随系统主题，并支持聊天背景设置。
- **皮肤包**：颜色、形状、间距和版式都可以整套替换，支持变量与状态；
  可从文件或剪贴板导入，也能把当前配色导出分享。格式见 [docs/SKIN.md](docs/SKIN.md)。

## 模型与服务

Burrow 支持配置多个 AI 服务渠道，并可以在对话中快速切换提供商和模型。

应用提供以下常用服务的配置入口：

- ChatGPT 订阅账号
- OpenAI API
- Anthropic 及 Anthropic 兼容服务
- DeepSeek
- GLM
- Kimi
- 硅基流动
- xAI
- Google Gemini（API Key，或用 Google 账号登录走 Vertex AI）
- Ollama 与本地模型
- 其他 OpenAI 兼容 API

部分服务可以使用 OAuth 登录，也可以通过 API Key 连接。每个渠道都可以单独配置模型、代理和生成参数。

ChatGPT 和 Grok 走设备码登录（在任意设备的浏览器里输一串码）；Google 走浏览器回跳登录，
必须在本机浏览器里完成。Google 默认使用随 gemini-cli 公开分发的 OAuth 客户端凭据，
也可以在渠道管理里换成自己在 Google Cloud Console 建的客户端。

> **Gemini 怎么接**：最省事的是 API Key —— 新建渠道时选预设「Google Gemini（API Key）」，
> 地址会自动填成 `https://generativelanguage.googleapis.com/v1beta/openai`。
> 从 Google 文档里复制的 `.../v1beta/models/<模型>:generateContent` 是**原生 REST 端点**，
> 填进来会 404。
>
> Google 账号登录里的「Code Assist」那一项，2026-09 实测已被 Google 从个人免费额度里
> 切掉（返回 `UNSUPPORTED_CLIENT`），登了多半用不了；要用 Google 账号请走 Vertex AI，
> 需要自己的 GCP 项目并开通计费。

每个渠道还可以单独设置：对话模型能否直接看图、用哪个模型做图片识别，
以及系统提示词的发送方式（少数服务不接受 system 消息，可改为并入首条用户消息）。

## 两种使用方式

### 聊天模式

适合日常问答、内容创作、资料整理、头脑风暴和普通编程咨询。在该模式下，AI 不会操作终端或任务文件。

### 终端模式

适合需要 AI 实际执行的任务，例如阅读项目、修改代码、运行脚本、分析文件和使用命令行工具。用户可以根据需要选择审批方式和沙箱级别。

## 界面概览

Burrow 以对话页为首页，并提供简洁的即时通讯式交互：

- 顶部显示会话标题、当前提供商和模型。
- 对话消息支持 Markdown、代码块和流式更新。
- 输入区可快速切换对话模型和嵌入模型，也可以附带图片。
- 顶栏可为当前会话单独设置系统提示词，设了之后图标会点亮。
- 侧边栏用于管理对话、模型账号、渠道、Skills 和应用设置。
- 内置终端和检查点页面可从对话页快速进入。

## 适用场景

Burrow 适合希望在手机上使用 AI 完成实际任务的用户，包括：

- 随时进行 AI 对话与写作。
- 在移动设备上阅读和调整代码。
- 运行 Python、Shell 及其https://ai.google.dev/他命令行任务。
- 处理本地文件和小型项目。
- 使用云端模型或本地模型搭建私人 AI 工作环境。
- 在外出时查看、继续或恢复 Agent 任务。

## 当前状态

Burrow 目前处于早期开发阶段，界面、功能和兼容性仍在持续完善。在用于重要文件或长时间任务前，建议保留额外备份。
